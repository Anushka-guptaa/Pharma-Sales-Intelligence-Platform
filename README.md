# Pharmaceutical Sales Analytics
## An end-to-end pharmaceutical sales analytics project that integrates Python, MySQL, SQL, and Power BI to transform raw sales data into actionable business insights, with future enhancements including forecasting and intelligent decision support.

## 2. Project Description:
   
   Dataset ->

• Pharmaceutical Sales Dataset
• Sales transactions from distributors
• Years Covered: 2017–2020
• Countries: Germany & Poland

  Technologies Used ->

• Python • Pandas • MySQL • SQL • Power Query • DAX • Power BI

  Tasks Performed ->

✔ Exploratory Data Analysis
✔ Removed duplicate records
✔ Validated Sales calculations
✔ Investigated negative quantities
✔ Created Month column
✔ Imported cleaned data into MySQL
✔ Built SQL database
✔ Connected Power BI to MySQL
✔ Used Power Query for transformations
✔ Worked with a Star Schema model
✔ Created DAX measures
✔ Built an interactive dashboard

## 3. Project Pipeline

| Stage | Work Done |
|--------|-----------|
| Python | Data cleaning, preprocessing, and exploratory data analysis (EDA) |
| MySQL | Stored the cleaned dataset in a relational database |
| SQL | Queried, filtered, joined, and managed data for analysis |
| Power Query | Performed data transformation and loading (ETL) |
| Data Modeling | Designed a Star Schema and established relationships |
| DAX | Created KPIs, measures, and calculated columns |
| Power BI | Built an interactive dashboard with business insights |
